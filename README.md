# luxehair

LUXE HAIR CO — Premium E-Commerce Store for Virgin Hair & Couture Units.

## Overview
A high-end, editorial luxury e-commerce boutique designed for unprocessed raw virgin wigs, hair attachments, and botanical hair care formulations.

### Key Capabilities
- **Dual Currency Architecture**: Native support for Nigerian Naira (₦ NGN) and US Dollars ($ USD) with centralized exchange rate conversions.
- **Dual Payment Processing**:
  - **Paystack (NGN)**: Primary settlement for Nigerian-issued cards (Mastercard, Visa, Verve), direct bank transfer (Zenith Bank), and Pay on Delivery.
  - **Stripe (USD)**: Primary settlement for international & overseas cards (Visa, Mastercard, American Express, Apple Pay).
- **Luxury Frontend**: Built with React + Vite, custom typography (Cormorant Garamond & Montserrat), dynamic shopping bag drawer, and celebratory gold confetti.
- **Full Backend API**: Node.js + Express with MongoDB, order tracking, admin command center, and webhook listeners.

## Tech Stack
- **Frontend**: React, Vite, Lucide Icons, Canvas Confetti
- **Backend**: Node.js, Express, Mongoose (MongoDB)
- **Gateways**: Paystack API, Stripe Checkout API
